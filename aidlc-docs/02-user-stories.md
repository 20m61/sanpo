# User Stories

## Primary User

As a user going out with one friend,  
I want sanpo to suggest conversation topics,  
so that I do not feel responsible for keeping the conversation alive.

## Shared Session

As two users on the same outing,  
we want to see the same third-friend prompts,  
so that the suggestions feel like a shared experience.

## Awkward Silence

As a user,  
I want to tap a "help" button when the conversation feels awkward,  
so that sanpo can suggest a light topic.

## Contextual Cue

As a user walking around,  
I want sanpo to suggest topics based on time, location, and outing plan,  
so that the prompts feel natural.

## XR Presence

As a user,  
I want sanpo to appear as a small ghost-like presence,  
so that it feels like a third friend is walking with us.

## Follow-up

As a user after an outing,  
I want sanpo to suggest a follow-up message,  
so that I can maintain the relationship without thinking too hard.
