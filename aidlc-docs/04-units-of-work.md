# Units of Work

## U1: Project Foundation

Set up repository, AI-DLC docs, README, and basic app structure.

## U2: Outing Session

Create and join two-person outing sessions.

## U3: Relationship Context

Store simple relationship context, known topics, and avoid topics.

## U4: Third Friend Agent

Use Strands Agents and Amazon Bedrock to generate context-aware conversation cues.

## U5: Topic Card System

Generate, store, and display topic cards.

## U6: Mock XR Presence

Display a cute ghost-like third friend and floating cue cards.

## U7: Notification Simulation

Show notification-like interventions during the outing.

## U8: Follow-up Generation

Generate post-outing follow-up messages.

## U9: Cost Control

Cache generated cards, limit LLM calls, and avoid always-on infrastructure.

## U10: Demo Preparation

Create demo scenario, screenshots, and submission explanation.
